## Project Overview

This repository contains the implementation and documentation for Natural Language Processing with Python Project 1. The project covers research abstract classification, machine learning model comparison, research document mining, topic modelling and an interactive visualisation.

## Project Components

### Question 1: Research Papers – Expert System

A Python-based model that classifies documents semantically based on context.

### Question 2: Model Comparison

Four machine learning models are implemented with the goal of obtaining better predictive performance than the baseline model.

### Question 3: Research Document Mining and Summarisation

A prototype system for tracking research trends in the field of artificial intelligence. The system applies topic modelling techniques to a small collection of recent AI research articles.

### Question 4: Deployment and Documentation

Documents the entire project, covering Questions 1 through 4, including project documentation and deployment.

## Project Structure

- `data/` — Research datasets and processed data
- `notebooks/` — Four assessment notebooks
- `docs/` — Project documentation and interactive LDA visualisation
- `deployment/` — Streamlit application, exported classifier and deployment instructions
- `requirements.txt` — Python dependencies
